TL;DR: TomoSphero is a PyTorch-based differentiable tomographic projector designed for spherical grids, enabling fast GPU-accelerated reconstruction for applications like planetary and solar tomography.


<details>
  <summary>Details</summary>
Motivation: Existing GPU-accelerated tomographic libraries mostly use Cartesian discretization, which is unsuitable for domains requiring spherical geometry (e.g., planetary/solar tomography).

Method: The authors developed TomoSphero—a differentiable, PyTorch-implemented projector operating on spherical grids, supporting cone-beam and parallel-beam projections, and compatible with arbitrary projection geometries and modern ML optimizers.

Result: TomoSphero enables efficient, differentiable forward projection on spherical grids with GPU acceleration, facilitating rapid prototyping and integration into learning-based reconstruction pipelines.

Conclusion: TomoSphero fills a gap in tomographic software by providing a flexible, differentiable, and spherical-grid-aware projector tailored for astrophysical and geophysical applications.

Abstract: Computational tomography is a tool for determining the internal structure of objects from a set of projections, typically taken along some regular path. In recent years, methods and GPU-accelerated libraries have emerged that allow for fast reconstruction from projections along more complicated paths. Most of these libraries rely on a Cartesian discretization of the object, which is not appropriate for all scenarios. We present TomoSphero, a differentiable tomographic projector over spherical grids which are often used in planetary and solar tomography. TomoSphero is designed to be used as a building block in reconstruction algorithms and includes common projection types such as cone-beam and parallel-beam, but is flexible enough to accommodate arbitrary projections.
